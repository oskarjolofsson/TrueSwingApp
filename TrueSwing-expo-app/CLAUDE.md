# True Swing Mobile APP

## What this project is
React native Expo project. Acts as a frontend interface for a golf-application that centers around videos. More specifically it offers the user to film, trim, prompt and upload videos as well as to review them later. This is all sent thorugh a backend API. The project is built arround Supabase Authentication.

## Repository layout
`app/` - all routes, sorted by authentication level. No real logic is supposed to be in here, instead features are linked
`features/` - all features and corresponding pages.


## Architecture rules
Follow the repository layout


## Conventions
Leave light commenting on new code, the code that might not appear to be obvious at first


## Commands
